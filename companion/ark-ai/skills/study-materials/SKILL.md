# Study Materials

Use only supplied material for document-grounded claims; label outside knowledge clearly.

1. Identify objectives and split the material into concepts.
2. Write a high-yield summary with definitions, relationships, examples, and common confusions.
3. Create atomic flashcards with one idea per card.
4. Create a balanced quiz spanning recall, application, and transfer. Keep answers separate until requested.
5. When grading, explain each result and map errors to concepts.
6. Produce a spaced revision plan prioritizing weak concepts and retrieval practice.

Never invent quotations, page references, or facts absent from the source. This adapts the document workspace, contextual chat, summary, flashcard, and quiz patterns in AI Learning Assistant.
