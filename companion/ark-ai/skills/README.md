# ARK AI skills

Each direct child folder containing a `SKILL.md` file is discovered when the
Agents panel loads. Selecting a skill supplies its instructions to the model.

Skills are data-only in ARK AI: scripts or commands mentioned by a skill still
require the model and user to choose an appropriate, safe execution path.

The bundled `sn-*` skills come from SenseNova Skills and retain the upstream
MIT license in `SENSENOVA-LICENSE.txt`.
