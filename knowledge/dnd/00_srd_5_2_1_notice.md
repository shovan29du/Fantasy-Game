# D&D SRD 5.2.1 Notice

This knowledge folder is updated for the latest redistributable D&D rules baseline available as of August 1, 2026: **System Reference Document v5.2.1**.

The official SRD page states that SRD v5.2.1 contains D&D rules content that creators can use under Creative Commons. The official D&D Beyond SRD page lists English SRD v5.2.1 as published May 1, 2025 and notes the page was last updated March 2, 2026.

Source: https://www.dndbeyond.com/srd

This project should not bundle copyrighted D&D books, adventures, settings, artwork, fiction, or non-SRD rules text unless the user has a separate legal right to use them. Use SRD-compatible summaries, original guidance, and links to official sources.
